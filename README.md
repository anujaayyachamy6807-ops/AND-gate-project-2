# **AND AND OR LOGIC GATES USING BREADBOARD**

## **Aim**

To design and construct simple AND and OR logic gate circuits using a breadboard, two push buttons, LEDs, resistors, and a battery, and to demonstrate the basic operation of digital logic gates using hardware components.

## **Problem Statement**

Digital logic gates are the basic building blocks of digital electronic systems. Understanding their operation only through theoretical diagrams can be difficult for beginners. Therefore, a simple and low-cost hardware circuit is required to demonstrate how different input combinations produce different output conditions in AND and OR logic gates.

## **Proposed Solution**

The proposed solution is to construct AND and OR logic gate circuits on a breadboard using two push buttons as input switches and LEDs as visual indicators. The two push buttons represent the input signals, while the output LED indicates the logic condition.
In the AND gate, the output LED turns ON only when both push buttons are pressed. In the OR gate, the output LED turns ON when either one or both push buttons are pressed. This provides a simple and practical demonstration of digital logic.


## **Components Required**

* Breadboard: Used to assemble the circuit without soldering.  
* Two Push Buttons: Used as the two input switches.  
* LEDs: Used to indicate the input and output conditions.  
* Resistors: Used to limit current and protect the LEDs.  
* Battery / DC Power Supply: Provides power to the circuit.  
* Jumper Wires: Used to make electrical connections between components.

---

## **Construction Procedure**

### **Step 1: Design and Layout**

1. Connect the positive and negative power rails of the breadboard to the battery.  
2. Place the two push buttons on the breadboard.  
3. Label the two push buttons as Input A and Input B.  
4. Connect LEDs through suitable resistors to indicate the required input and output conditions.

Step 2: Constructing the AND Gate

1. Connect the two push buttons so that current can reach the output only when both buttons are pressed.  
2. Connect the output of the circuit to an LED through a current-limiting resistor.  
3. Connect the LED and resistor to the appropriate power and ground connections.  
4. Press the first button only and observe the output LED.  
5. Press the second button only and observe the output LED.  
6. Press both buttons together and observe the output LED.

The output LED should turn ON only when both Input A and Input B are ON.

### **Step 3: Constructing the OR Gate**

1. Construct the OR gate circuit on the breadboard using the same two push buttons.  
2. Connect the two input paths so that current can reach the output when either button is pressed.  
3. Connect the output to an LED through a suitable resistor.  
4. Press the first button and observe the output.  
5. Release the first button and press the second button.  
6. Press both buttons together.

The output LED should turn ON when either one or both push buttons are pressed.

### **Step 4: Testing the Circuit**

Test all possible combinations of the two push buttons.

| Input A | Input B | AND Output | OR Output |
| :---- | :---- | :---- | :---- |
| OFF | OFF | OFF | OFF |
| OFF | ON | OFF | ON |
| ON | OFF | OFF | ON |
| ON | ON | ON | ON |

**This table verifies the basic truth tables of the AND and OR logic gates.**

### **Step 5: Final Assembly**

1. Check all breadboard connections carefully.  
2. Ensure that the LED polarity is correct.  
3. Ensure that suitable resistors are connected with the LEDs.  
4. Check that the push buttons operate correctly.  
5. Test the circuit using all four possible input combinations.
